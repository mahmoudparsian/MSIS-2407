## What the Guides Cover

| Step | What you do | When |
|:---:|---|---|
| **0** | Get the course files | **Before the first class** |
| **1** | Install Python | **Before the first class** |
| **2** | Install and check DuckDB, Marimo, Pandas, and sqlglot (one script) | **Before the first class** |
| **3** | Verify everything together in a Marimo notebook | **Before the first class** |

**Set aside about 45 minutes** for Steps 0–3, and do them **before the
first class**.
